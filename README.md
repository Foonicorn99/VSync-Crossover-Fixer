# VSync-Crossover-Fixer
Small app that forces crossover apps to adhere to macOS VSync

This app creates a little blue dot on your screen. You can drag it around to wherever you want on your screen. This dot vibrates imperceptibly back and forth in time with your monitor's refresh rate, and this forces games running though crossover to this refresh rate. The difference is most notable in games like CS2, where both the VSync option and locking the game to 60 fps doesn't create a smooth 60 fps. See example below. Taken on 60 hz MacBook Air:
